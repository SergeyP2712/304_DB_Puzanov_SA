# Лабораторная работа 2: ETL процесс и создание БД SQLite

## Требования к окружению:
- Python 3.x (установлен и добавлен в PATH)
- SQLite 3.x (утилита sqlite3 доступна в командной строке)

## Структура файлов:
- **make_db_init.py** - Python-утилита для генерации SQL-скрипта
- **db_init.bat** - Shell-скрипт для запуска утилиты и создания базы данных
- **db_init.sql** - сгенерированный SQL-скрипт (создается автоматически)
- **movies_rating.db** - база данных SQLite (создается автоматически)
- Исходные данные: movies.csv, ratings.csv, tags.csv, users.txt

## Как запустить:
1. Убедитесь, что Python 3 и SQLite установлены
2. Выполните команду: `bash db_init.bat`
3. Будет создана база данных movies_rating.db с таблицами и данными

## Результат выполнения:
- movies: 9742 записей
- ratings: 18773 записей
- tags: 3683 записей
- users: 943 записей

## Время выполнения:
Скрипт отрабатывает за < 2 секунд благодаря использованию транзакций (BEGIN TRANSACTION / COMMIT)
